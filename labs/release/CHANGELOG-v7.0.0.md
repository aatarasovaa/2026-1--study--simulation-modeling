# Changelog

## [7.0.0] - 2026-05-10

### Added

- Реализация модели M/M/c (многоканальная СМО с пуассоновским входным потоком)
- Реализация модели Росса (система с конечным числом машин, резервом и ремонтом)
- Скрипт `scripts/mmc_model.jl` для моделирования M/M/c
- Скрипт `scripts/ross_model.jl` для моделирования системы Росса
- Параметрические исследования для модели M/M/c (различное число каналов c)
- Параметрические исследования для модели Росса (различное число ремонтников и резервных машин)
- Графики динамики числа заявок в системе для M/M/c
- Графики изменения числа исправных машин для модели Росса
- Мониторинг загрузки ремонтника и длины очереди на ремонт
- Литературное оформление кода с использованием `Literate.jl`
- Сгенерированные Jupyter Notebook для обеих моделей
- Quarto-документация для обеих моделей
- Пакеты: `ConcurrentSim`, `ResumableFunctions`, `Distributions`, `StableRNGs`

### Changed

- Структура проекта приведена к стандарту DrWatson
- Код преобразован в литературный стиль

### Fixed

- Исправлены ошибки при инициализации проекта DrWatson
- Исправлены пути к файлам в конфигурации Quarto

## [2.0.0] - 2026-02-25

### Added

- Реализация модели SIR (дифференциальные уравнения)
- Реализация модели Лотки-Вольтерры (хищник-жертва)
- Скрипт `scripts/sir_ode.jl` для моделирования эпидемии
- Скрипт `scripts/lv_ode.jl` для моделирования популяционной динамики
- Параметрические исследования для обеих моделей
- Литературное оформление кода
- Интеграция с Quarto для генерации отчётов

## [1.0.0] - 2026-02-15

### Added

- Инициализация проекта DrWatson
- Настройка рабочего пространства
- Реализация модели экспоненциального роста
- Скрипт `scripts/01_exponential_growth.jl`
- Параметрическое сканирование для модели экспоненциального роста
- Литературное программирование с использованием `Literate.jl`
- Скрипт `scripts/tangle.jl` для генерации производных форматов
- Настройка Quarto для документации
- Интеграция кода в отчёт
